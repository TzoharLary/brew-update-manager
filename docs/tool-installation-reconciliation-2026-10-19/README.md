# איחוד התקנות Node, Deno, Ansible, uv ו־Pandoc

עדכון מאוחר יותר באותו יום: עותק Node של Homebrew הוסר לאחר בדיקות צרכנים נוספות, ו־MacPorts הותאם ל־Tahoe. ראו [הטיפול המאוחר והמצב הנוכחי](../macports-recovery-2026-10-19/README.md). הטבלאות להלן מתעדות את שלב האיחוד שקדם לכך.

19.10.2026. האפליקציה עודכנה והופעלה מחדש בגרסה 1.1.19. נבדקו נתיבי המשתמש הרגילים, קישורים, הגדרות PATH ממוקדות, קבלות וגרסאות בפועל. לא בוצעה סריקה רקורסיבית של כל תיקיית הבית.

## הבהרת התפקידים

Node ו־Deno הם סביבות הרצה ל־JavaScript; Ansible הוא כלי אוטומציה; Pandoc ממיר מסמכים. uv הוא כלי לניהול Python וחבילות/כלי Python. אלה אינם חמישה מנהלי חבילות מקבילים ל־Homebrew. בטיפול הקודם הותקנו גרסאות חלופיות שלהם, ולא חמישה כלים שמטרתם להחליף את Homebrew.

## מה היה ומה נשאר

| כלי | התקנה קודמת שנמצאה | גרסה פעילה לאחר הטיפול | הפעולה |
|---|---|---|---|
| Node | Homebrew 26.0.0, נכשל בטעינת libada.3; קבלת מתקין רשמי ישנה מציינת 22.15.0 | 26.12.0 בהתקנה הרשמית שהמנהל הפעיל | נשמר Node הפעיל. קבלת המתקין ההיסטורית אינה התקנת Node נוספת שנמצאה בפועל |
| Deno | Homebrew 2.7.14 | 2.9.7 בהתקנה הרשמית שהמנהל הפעיל | הוסר עותק Homebrew הישן לאחר גיבוי |
| Ansible | Homebrew 13.6.0_1, core 2.20.5 | distribution 14.5.0, core 2.21.5 בסביבת Pixi | הוסר עותק Homebrew הישן לאחר גיבוי; תצורת המשתמש וה־collections נשמרו |
| Pandoc | Homebrew 3.9.0.2 | 3.12.1 בסביבת Pixi | הוסר עותק Homebrew הישן לאחר גיבוי |
| uv | עצמאי ב־`~/.local/bin` בגרסה 0.9.7, Homebrew 0.11.18, ועותק Pixi שהוספנו בגרסה 0.13.1 | 0.13.1 ב־`~/.local/bin/uv`, וגם uvx באותו נתיב | ההתקנה העצמאית עודכנה באמצעות המעדכן הרשמי. עותק Homebrew הוסר; סביבת Pixi ופקודות התיווך המיותרות הועברו לגיבוי |

לארבעת הכלים האחרים לא נמצאה התקנה עצמאית בנתיבי המשתמש המקובלים שנבדקו. זו בדיקה ממוקדת, ולא הוכחה שאין executable נוסף במקום אחר במחשב. נתיב קיים אינו הוכחה לכוונת המשתמש, אך התקנת uv העצמאית הקודמת נשמרה במקום שבו נמצאה. בניגוד להשערה הראשונית, גרסתה לא הייתה חדשה מגרסת Homebrew.

Node של Homebrew נשאר בגלל קשר תלות מתועד של MongoDB. הוא עדיין אינו תקין; הפקודה הפעילה היא Node 26.12.0 התקין. ההחלטה להסיר את הקג הישן צריכה להישען על בדיקת צרכני MongoDB והעברתם, ולא על כך שהפקודה `node` במעטפת עובדת. אין כאן הכרזה שכל כפילות במחשב נפתרה.

ה־npm הגלובלי הקודם ב־`/usr/local/lib/node_modules` ונתוני הכלים הגלובליים נשמרו. Node הפעיל כולל npm 11.20.0; ה־npm הישן 11.17.0 הוא התקנה נפרדת שלא הוסרה במסגרת איחוד חמשת הכלים. קבלת npm ישנה 10.9.2 אינה הוכחה שגרסה זו עדיין מותקנת.

האפליקציה שומרת uv עזר פרטי ב־Application Support לצורכי runtime. הוא אינו פקודת uv של המשתמש ואינו מופיע כעותק ב־PATH. סביבת ההרצה הפרטית נשמרה כדי שהסרת חבילת משתמש לא תשבור את מנהל העדכונים.

## שינויי האפליקציה שנדרשו לאיחוד

- מלאי הכלים המנוהלים אינו נעלם לאחר הסרת קג Homebrew הכפול. שמות שנמצאים ברישום ההתקנות מקבלים metadata נפרד מהקטלוג; כשל בבדיקת הקטלוג גורם לשגיאה ולא להכרזה שכולם מעודכנים.
- uv הקיים אומץ ברישום עם בעלות `standalone_uv` ו־prefix של `~/.local`. תכנון העדכון בודק `uv self update --dry-run`; ביצועו משתמש באותו executable ובאותו נתיב, ואינו יוצר סביבת Pixi נוספת.
- גילוי גרסאות בלתי תלוי לכל ספק ומודל כללי של כמה התקנות לאותה תוכנה עדיין שייכים לתכנית הארכיטקטורה. תיקון זה אינו יישום מלא שלה.

## אימות ושחזור

14 בדיקות Python עברו, כולל הישארות כלי במלאי לאחר הסרת קג וביצוע עדכון uv בנתיב המקורי ללא יצירת סביבה חדשה. שלושת קבצי backend באפליקציה הארוזה הושוו למקור. במלאי טרי של האפליקציה כל חמשת הכלים מופיעים בגרסאות ובמסלולים שנבחרו; ngrok נשאר מוחרג. נבדקו גם הרצת קוד ב־Node וב־Deno, Ansible ping מקומי, המרת Markdown ב־Pandoc וגרסת uv.

לפני הסרה נשמרו קגי Homebrew ואומתו התוכן והקישורים שלהם. הגיבוי מכיל 36,858 קבצים רגילים מארבע החבילות, נוסף על קישורים ותיקיות. נשמרו גם קובצי uv/uvx הקודמים, קבלת uv, רישום הכלים, הגדרות האפליקציה והאפליקציה הקודמת. הגיבויים בסל המחזור לא רוקנו; אין כאן טענה שפונה אותו נפח בדיסק. לא בוצע autoremove של תלויות או מחיקת נתוני משתמש.
