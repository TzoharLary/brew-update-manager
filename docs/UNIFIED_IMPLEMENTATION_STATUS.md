# Unified Intel update manager — implementation status

## עדכון מימוש בענף 1.3.4 (20.10.2026)

קוד עבודה בענף \`feat/unified-intel-134-foundations\`, ב־PR טיוטה מס' 1.
זו **אינה גרסה מותקנת או מוכנה להפצה**. הנתונים של משתמש ה־Mac אינם שונו
בידי הסוכן. ה־CI מבצע בדיקות תחביר ו־packaging smoke בלבד, לא את בדיקות
ה־Python/Electron המלאות או מעבר הספק האמיתי.

קיים בקוד:
- בחירת גרסה וספק עם החלטות שמורות, סיבות, 15 דקות תוקף ו־fingerprint.
- כיסוי עדכונים בינאריים של Homebrew formula, MacPorts וכלים מנוהלים ב־Pixi.
- ניהול בעלות על התקנות, נעילת פעולות בין תהליכים, ורישום request IDs למניעת
  הפעלה כפולה אחרי ניתוק.
- תשתית מעבר Homebrew ל־MacPorts לפרופילים מוכרים, עם גיבוי קג, יומן,
  בדיקת שימוש, ניתוב פקודות שמגן על קבצים זרים וסקירת resume/rollback.
- UI אחיד, תוכניות API, כפתור פעולה אחד, ותוצאות עם מזהי בקשה.
- סקריפט \`tools/verify-migration.py --checks/--full\` לגרסה 1.3.4.
  \`--full\` יכול להחליף את האפליקציה המקומית ודורש YES לשינוי חבילות.

עדיין לא הוכח / נשאר לבדיקה או להשלמה:
- קבלת Mac אמיתית של IWYU אחרי החלפה, ניקוי, שחזור והפעלה מחדש.
- פיילוט Pixi אמיתי; מעבר חדש מ־Homebrew ל־Pixi אינו מופעל עדיין
  כעסקה נתמכת (עדכון של סביבת Pixi מנוהלת קיים בנפרד).
- קבלה מעמיקה של Cask ובדיקת closure/metadata לכל שאר החבילות.
- רגרסיות HTTP/renderer, תרחישי כשל מלאים ו־restore של bundle 004.
- חתימות קוד/חבילה, ניתוב ב־login shell, הרשאת מנהל ו־recovery נבדקים
  בקבלה המקומית; קיומן של הפונקציות אינו הוכחת התנהגותן ב־Mac.

**אין לסגור T03/T04/T07** לפני דוח \`--checks\` מלא ודוח \`--full\`
שמפריד הצלחה מדמה מקבלה אמיתית. אין לאשר מעבר בלתי מזוהה או לפרסם release.
